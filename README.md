# 현장연료 안심확인 — 시제품 v0.3

이동판매(홈로리) 석유의 주유 1건마다 디지털 연료 확인서(QR)를 발급하고, 현장 관리자가 QR로 확인·신고하며,
관리원이 공공데이터로 이동판매 우선지역을 고르는 흐름을 한 페이지로 시연한다.

- 실행: https://best5218o-ux.github.io/fuel-anshim-check/ (로그인·설치 없음, 단일 HTML)
- 데이터 출처: 소방청 2021 위험물 통계, 경기·경남·전남 위험물 제조소등 현황, 인천시 석유 품질검사 위반 공개자료,
  산업통상부 석유판매가격 최고액 고시, 한국석유관리원 전산보고 주유소 공개 목록 등(화면 하단 출처 표기)
- 무결성 코드는 시연용 해시이며, 실제 운영은 관리원 서버 전자서명을 전제로 한다.
- 판매업소 목록은 시연용이며, 실제 운영은 관리원 석유판매업 등록 DB와 대조한다.
